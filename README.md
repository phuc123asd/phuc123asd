### 🐾 Project: Animal Detection with Faster R-CNN

Implemented an **object detection system** using the **Pascal VOC dataset**.

Key components:

* Dataset: **VOC Dataset**
* Model: **Faster R-CNN**
* Framework: **PyTorch**
* Task: Detect animals in natural images

Pipeline:

1. Dataset preprocessing
2. Training object detection model
3. Bounding box prediction
4. Evaluation and inference

This project helped me understand:

* Region Proposal Networks
* Feature extraction with CNN
* Detection pipelines
* Training large deep learning models
